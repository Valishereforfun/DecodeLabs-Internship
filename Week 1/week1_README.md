# Week 1 – Data Cleaning & Preparation

**Project:** DecodeLabs Data Analytics Internship | Project 1  
**Tool:** Microsoft Excel  
**Dataset:** E-commerce orders dataset (1,200 rows, 14 columns)

---

## Objective

Clean a raw, messy dataset so it is accurate and ready for analysis.
The goal was zero duplicate IDs and zero incorrectly formatted dates.

---

## What I Did

- Identified and removed duplicate records from the dataset
- Handled missing and null values across key columns
- Standardized text formatting — consistent capitalization, trimmed whitespace
- Corrected date formats to ensure uniformity across the Date column
- Validated that all OrderIDs were unique (0% duplicate rate)
- Exported the cleaned dataset as both `.xlsx` and `.csv` for downstream use

---

## Key Takeaway

Data cleaning is the foundation of every analytics project. Bad data produces
bad insights no matter how powerful the tools. Getting this right first is what
makes everything downstream reliable.
