Dataset
All four projects were built on the same e-commerce dataset containing 1,200 orders
across 14 columns: OrderID, Date, CustomerID, Product, Quantity, UnitPrice,
ShippingAddress, PaymentMethod, OrderStatus, TrackingNumber, ItemsInCart,
CouponCode, ReferralSource, and TotalPrice.
---
Week Summaries
Week 1 – Data Cleaning: Took the raw dataset and removed duplicates, handled
missing values, standardized text formatting, and corrected data types to produce
a clean, analysis-ready file.
Week 2 – Exploratory Data Analysis: Loaded the cleaned data into Power BI,
used Power Query to further transform and standardize the data, then built KPI
cards showing key statistics: Median order value (823.62), Total Revenue (1.26M),
Total Orders (1K), and Average Order Value (1.05K).
Week 3 – SQL Series: Imported the dataset into MySQL Workbench and wrote
82 lines of SQL covering SELECT, WHERE, AND/OR filtering, ORDER BY, GROUP BY,
COUNT, SUM, and AVG — running 43+ successful queries against the analytics_table.
Week 4 – Data Visualization & Insights: Built pivot tables and charts in Excel
to summarize revenue by year, product, referral source, and order status, then
documented 5 business insights from the findings.
